# 编码 agent broker（可选模块）

让主人能在 QQ 里用自然语言让一个 AI 编码助手给机器人加/改功能。

## 工作原理
```
QQ 主人: /pc 帮我在群里加一个"每日天气"命令
   ↓ 引擎 relay_to_opencode()
relay/inbox/<seq>.txt          ← broker 轮询到这里
   ↓ broker 处理（local 内置 agent 或 opencode）
relay/outbox/<seq>.txt
   ↓ 主人: /get <seq>
QQ 收到 AI 的答复
```
引擎侧的 `RELAY_DIR` 必须和本模块 `agent.config.json` 的 `relay_dir` 指向**同一个目录**。

## 前置
1. 引擎 `config.json` 里填好 PC 执行端（`executor_url` / `executor_secret`），并启动 `modules/pc` 的
   `启动电脑端.ps1` —— 引擎是通过执行端把消息写进 `relay/inbox` 的。
2. 引擎 `config.json` 把 `relay_dir` 设为该 relay 目录（例如仓库根下的 `relay`）。
3. 本模块需要 Python 3.10+（`local` 后端用仓库已配好的大模型 key，无需额外依赖）。

## 配置
复制 `配置模板.json` 为 `agent.config.json`，填：
| 键 | 说明 |
|----|------|
| `backend` | `local`（内置 agent）或 `opencode`（调用外部 opencode CLI） |
| `relay_dir` | relay 目录，**必须**与引擎 `relay_dir` 一致 |
| `repo_dir` | 机器人仓库根目录（留空=自动取上两级） |
| `api_key` / `base_url` / `model` | 留空则自动用仓库 `config.json` / `.env` 的 deepseek 配置 |
| `allow_shell` | 是否允许内置 agent 执行 PowerShell（**默认 false，谨慎开启**） |
| `allowed_roots` | 内置 agent 可读写的目录白名单（留空=仅仓库根） |
| `opencode_cmd` | `opencode` 后端要执行的命令，默认 `opencode run` |

## 启动
```powershell
.\启动编码助手.ps1     # 后台启动，日志见 agent.log
.\停止编码助手.ps1      # 停止
```
或双击 `启动编码助手.bat`。

## 两种后端
- **local**：内置纯 Python 编码 agent。用 OpenAI 兼容接口的 function calling，工具包括
  `list_dir` / `read_file` / `write_file` / `replace_in_file` /（可选）`run_shell` / `finish`。
  只对 `allowed_roots` 内的路径生效。适合不想装额外 CLI 的场景。
- **opencode**：`opencode run "<任务>"`，工作目录=仓库。需另行安装 opencode。

## 安全
- 这等于"自然语言 → 改代码"，只应给**信任的主人**用。引擎已限制只有主人能触发 `/pc`。
- 内置 agent 默认**不能执行 shell**（`allow_shell=false`），也只在白名单目录里读写。
- 建议先让 agent 说明要改什么，确认后再让它动手；仓库建议用 git，便于回滚。
