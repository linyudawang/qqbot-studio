# PC 控制模块（可选）

让机器人在**这台 Windows 电脑**上执行 PowerShell 命令。默认**不启用**，且有安全风险，请只对自己信任的人开放。

## 两种用法

### A. 机器人和电脑在同一台机（最简单，Windows 为主时用这个）
1. 复制 `配置模板.json` 为 `config.json`，把 `secret` 改成一串随机字符串。
2. 运行 `控制电脑.ps1`，选 `Y` 启动执行端（监听 `127.0.0.1:8765`）。
3. 在框架根目录的 `config.json` 里填：
   - `"executor_url": "http://127.0.0.1:8765"`
   - `"executor_secret": "<与上面相同的 secret>"`

### B. 机器人跑在远端服务器，电脑在本地（需要反向隧道）
1. 同样复制并填好 `config.json`，另外填 `ssh_host`（`user@服务器`）和 `ssh_key`（私钥路径）。
2. 运行 `控制电脑.ps1` 选 `Y`：会同时起执行端 + SSH 反向隧道（`隧道.ps1` / `隧道NapCat.ps1`）。
3. 服务器端 `config.json` 的 `executor_url` 填 `http://127.0.0.1:8765`。

## 文件
| 文件 | 作用 |
|------|------|
| `控制电脑.ps1` | 启停菜单（推荐入口） |
| `启动电脑端.ps1` / `停止电脑端.ps1` | 启动 / 停止 |
| `执行端.ps1` | 执行端（HTTP，收 `X-Secret` 头） |
| `隧道.ps1` / `隧道NapCat.ps1` | SSH 反向隧道保活（用法 B） |
| `安装开机自启.ps1` | 开机自启（写启动项，无需管理员） |

## 安全须知
- `secret` 必须随机且保密；`ssh_key` 用专用密钥，别用主力私钥。
- Executor 只绑定 `127.0.0.1`，不要改绑 `0.0.0.0`，否则同网段任何人都能跑命令。
- 不使用时请 `停止电脑端.ps1` 关闭。
